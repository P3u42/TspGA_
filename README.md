About the Project

This project explores the application of Genetic Algorithms (GAs) to solve the Traveling Salesperson Problem (TSP), a well-known combinatorial optimization problem.

The goal of the TSP is to find the shortest possible route that visits a set of cities exactly once and returns to the starting point.

As the number of cities increases, the number of possible routes grows rapidly, making exhaustive search computationally expensive. Genetic Algorithms offer an alternative approach by evolving a population of candidate solutions over successive generations.

The project was developed in Unity using C# and the GeneticSharp library to implement and execute the evolutionary algorithm.
